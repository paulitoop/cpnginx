# КриптоПро Nginx: конфигурации и автоматизация

Прототип ВКР по автоматизированному конфигурированию клиентских
ГОСТ TLS/mTLS-шлюзов с помощью Ansible и Vault.

Для переносной демонстрации начните с [lab/README.md](lab/README.md).
Ubuntu-шлюзы и сервер партнёра работают в Docker, Ansible работает в WSL.
Можно выбрать один или два шлюза. Прежние VirtualBox VM не изменяются.

- `integrations/demo/`: активные YAML интеграций для демонстрации.
- `integrations/examples/`: примеры плоского формата без балансировщиков.
- `automation/`: playbook-файлы и inventory для самостоятельных Linux-узлов.
- `lab/`: новый управляемый контейнерный стенд.
- `lab/playground/`, `lab/vault/`: прежние вспомогательные варианты стенда.
- `certs/`: прежний публичный тестовый сертификат; новый lab создаёт свежий УЦ.

Роли: [установка](https://github.com/paulitoop/ansible-role-cpnginx_install),
[конфигурирование](https://github.com/paulitoop/ansible-role-cpnginx_configure).
В конфигурации интеграции задаются целевой сервис, локальный порт и ссылка
на клиентский PFX в Vault. Состав шлюзов задаётся Ansible inventory.

Дистрибутивы КриптоПро, образы с ними, PFX, пароли, лицензии и локальное
состояние Vault в репозиторий не входят. Нужен собственный дистрибутив и
соблюдение условий его использования. Корпоративные CI-ресурсы исключены.
Лицензия на распространение исходного кода пока не выбрана.
