# КриптоПро Nginx: конфигурации и автоматизация

Материалы прототипа ВКР по автоматизированному конфигурированию клиентских
ГОСТ TLS/mTLS-шлюзов. Существующие YAML-описания интеграций и доверенный
тестовый сертификат сохранены вместе с историей репозитория.

## Структура

- `inventory/`: YAML-описания интеграций, загружаемые ролью конфигурирования.
- `certs/`: доверенные сертификаты для этих интеграций.
- `automation/`: playbook-файлы, Ansible inventory, скрипты запуска и
  `requirements.yml` со ссылками на роли.
- `lab/playground/`: исходники контейнерного стенда и вспомогательные скрипты.
- `lab/vault/`: локальная конфигурация лабораторного Vault и CLI-wrapper.

## Роли

- Установка: https://github.com/paulitoop/ansible-role-cpnginx_install
- Настройка: https://github.com/paulitoop/ansible-role-cpnginx_configure

Начните с `automation/README.md`. Дистрибутивы КриптоПро, PFX, пароли,
лицензионные значения, `.env`, результаты инициализации Vault и журналы
не входят в публикацию. Подготовьте их самостоятельно для своего стенда.

## Статус

Исследовательский прототип. Публикационная копия проверяется статически;
полноценное развёртывание после переноса в эти репозитории не выполнялось.
В роли обработки PFX остаются известные ограничения скрытия вывода и очистки
при ошибках; наличие Vault само по себе не устраняет эти ограничения.
Корпоративные CI-ресурсы исключены. Автоматический запуск развёртывания
через GitHub Actions в этой версии не настраивается.
Лицензия на распространение исходного кода пока не выбрана.
