# Локальный Vault для лабораторного стенда

Запускается командой `docker compose up -d` из этого каталога.
`bin/vault` вызывает Vault CLI внутри контейнера `nir-vault`.

Инициализацию и unseal выполните самостоятельно. Root token и unseal keys
храните вне репозитория; `.vault-init.json` исключён из Git. Не публикуйте
данные Docker volume. Для штатных операций Ansible используйте отдельный
AppRole с разрешением чтения только нужных записей, а не root token.

Роль конфигурирования ожидает запись KV v2 с полями `pfx` и `pin`:
`pfx` содержит base64 ZIP-архива с PFX, `pin` содержит пароль этого PFX.
Создайте тестовую запись из собственных тестовых ключей. Готовые ключи,
пароли и данные инициализации в публикацию не включены.

Это локальная лабораторная конфигурация с HTTP. Не используйте её как
производственную конфигурацию Vault. Управляющий узел и Vault требуют
собственного разграничения доступа.
